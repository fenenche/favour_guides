Memory Techniques

Simple tricks to help you remember what you learn for longer.

Spaced Repetition

Instead of studying something once and forgetting it, review it again after a day, then a few days, then a week. Spacing out your review sessions helps move information into long-term memory.

Using Mnemonics

Mnemonics are memory tricks like acronyms or rhymes that help you recall information. For example, "Every Good Boy Does Fine" helps remember the musical notes E-G-B-D-F on a staff.

Teaching What You Learn

Explaining a topic to someone else (or even to yourself out loud) forces you to understand it clearly enough to teach it — which strengthens your own memory of it.
