Memory Techniques

Simple tricks to help you remember what you learn for longer.

Spaced Repetition

Review information again after a day, then a few days, then a week, to move it into long-term memory.

Using Mnemonics

Mnemonics are memory tricks like acronyms or rhymes that help you recall information.

Teaching What You Learn

Explaining a topic to someone else forces you to understand it clearly enough to teach it.
